Debian 12+ / Ubuntu 22.04+

{{de}}Paketquelle einmal hinzufügen, danach kommen Updates mit den normalen Systemupdates.{{en}}Add the package source once – after that, updates come with your normal system updates.{{/}}

sudo install -d /etc/apt/keyrings
sudo curl -fsSL https://apt.mirranet.de/mirranet.gpg \
    -o /etc/apt/keyrings/mirranet.gpg
echo "deb [signed-by=/etc/apt/keyrings/mirranet.gpg] https://apt.mirranet.de stable main" \
    | sudo tee /etc/apt/sources.list.d/mirranet.list
sudo apt update && sudo apt install freex-media-server
